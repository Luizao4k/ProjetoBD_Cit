# 🗺️ Roadmap Geral

Este roadmap apresenta a evolução macro do projeto **CITBD**.

Os detalhes de cada etapa encontram-se nos roadmaps específicos do **Backend** e do **Frontend**.

| Área         | Status |

# 🚧 Fase 1 — Backend

**Objetivo:** construir toda a camada de servidor seguindo os princípios de Domain-Driven Design (DDD) e Clean Architecture.

Principais entregas:

* [ ] Infraestrutura
* [ ] Importação inicial dos dados
* [ ] API REST
* [ ] Segurança
* [ ] Qualidade
* [ ] Deploy do backend

📄 Roadmap detalhado: `docs/roadmap/backend.md`

---

# ⬜ Fase 2 — Frontend

**Objetivo:** desenvolver a interface da aplicação e integrá-la ao backend.

Principais entregas:

* [ ] Estrutura da aplicação
* [ ] Interface do usuário
* [ ] Integração com a API
* [ ] Testes
* [ ] Deploy do frontend

📄 Roadmap detalhado: `docs/roadmap/frontend.md`

---

# ⬜ Fase 3 — Documentação

**Objetivo:** documentar toda a arquitetura e o funcionamento do sistema.

Principais entregas:

* [ ] Documentação do domínio
* [ ] Documentação da aplicação
* [ ] Documentação da infraestrutura
* [ ] Documentação da API
* [ ] Documentação do frontend
* [ ] Diagramas da arquitetura
* [ ] Guias de estudo

---

# ⬜ Fase 4 — Publicação

**Objetivo:** preparar o projeto para disponibilização pública.

Principais entregas:

* [ ] Docker
* [ ] CI/CD
* [ ] Licença
* [ ] Versão 1.0
* [ ] Revisão final da documentação

---

# 🎯 Objetivo Final

Disponibilizar um sistema completo para gerenciamento das informações da Coordenação de Inovação e Tecnologia (CIT), desenvolvido como projeto de estudo em **Engenharia de Software**, aplicando conceitos de **Domain-Driven Design (DDD)**, **Clean Architecture** e desenvolvimento **Full Stack**.
