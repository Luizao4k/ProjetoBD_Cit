# 🗺️ Roadmap do Frontend

Frontend do **CITBD**, responsável pela interface do sistema de gerenciamento das informações da Coordenação de Inovação e Tecnologia (CIT) das escolas da rede estadual do Pará.

O frontend será desenvolvido utilizando **React**, **TypeScript** e uma arquitetura baseada em funcionalidades (*Feature-Based Architecture*), priorizando componentes reutilizáveis, organização e manutenibilidade.
